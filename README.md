# Mercy Muema — Professional Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. It is suitable for deployment on Cloudflare Pages.

## Files
- `index.html` — page content and structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year

## Preview locally
Open `index.html` in a browser.

## Deploy to Cloudflare Pages
1. Push these files to the root of your GitHub repository.
2. In Cloudflare, open **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
3. Select the GitHub repository.
4. For a plain HTML site, leave the build command empty and set the build output directory to `/` (or the repository root, depending on the dashboard UI).
5. Deploy.
